> 本文是 `docs/13-创意资产库结构与命名规范.md` 的资产库内速查版。完整规则与决策理由以 docs/13 为准。
> 更新：2026-11-18（全面中文化重组后）。

## 2. 六态怎么标

状态在**三处同步**：① 目录分区 ② 清单 `状态` 字段 ③ 版本说明.md。

| 状态 | 分区目录 | 何时用 |
|---|---|---|
| 草稿 draft | `草稿/` | 探索中，未参与决策 |
| 评审 review | `评审/` | 已成形，待拍板 |
| 在用 approved | `在用/` | 当前采纳，单元内**唯一** |
| 历史 superseded | `历史/` | 曾被采纳，被新版取代 |
| 放弃 discarded | `放弃/` | 未选中/被否决 |
| 留档 archived | `留档/` | 截图/裁切/副本，非设计决策 |

> 关键：历史（上过台）≠ 放弃（没选上）；留档（非设计）≠ 放弃（被否的设计）。

## 3. 版本怎么命名

- 格式：`vNN-YYYYMMDD-<中文意图>`，如 `v02-20261118-显影暗房`。
- `v00-` 专用于未采纳方案；序号单调递增、不复用。
- 当前版本由所在页 `索引.md` + `status=approved` 表达；禁止改名 `final`、复制 `current`。
- 禁止命名：最终版 / 新版 / old / final / copy / 随机 hash。

## 4. 标签怎么打

六个正交维度用受控标签，不建目录：`用途 / 风格 / 场景 / 页面 / 主题 / 合规`。取值见 `90-元数据/标签词表.json`；新取值先登记词表再用。例：`风格:胶片日常`、`场景:夜景`、`合规:含AI标识`。

## 5. 新资产入库流程

```text
新素材 → 查 资产总清单.json 的 sha256/标签
  → 命中：复用，不重复落盘
  → 未命中：判来源 → 落入对应大类 + 状态分区
     → 派生必填 派生自；AI 生成填 生成工具/提示词路径
  → 打六维标签 → 写清单条目（状态三处同步）
  → 被代码引用：同步 web/public + 更新 运行时映射.json
  → 更新所属单元 索引.md → 跑校验门禁
```

## 6. 运行时副本

`代码仓库/web/public/` 是派生副本，不是第二份源。改动顺序：**改源 → 同步 public → 更新 `90-元数据/运行时映射.json` 的 source_path/sha256 → build + 404 检查**。`public/` 路径保持英文不变。
