## 3. 运行时映射（关键）

代码通过 `代码仓库/web/public/<path>` 引用资源，其源文件由 `manifests/运行时映射.json` 追溯：

| 运行时路径 | 源文件 | 派生 |
|---|---|---|
| `/brand/logo-horizontal.svg` | `brand/logo/标志-横版.svg` | 否（直接复制） |
| `/brand/logo-icon.svg` | `brand/logo/标志-图标.svg` | 否（直接复制） |
| `/templates/<id>.webp` | `templates/<id>/封面.webp` | 是（封面压缩版） |
| `/gallery/g06,g07,g09,g10,g12–g15.jpg` | `media/licensed/*.jpg` | 否 |
| `/gallery/g16–g22.png` | `media/generated/*.png` | 否 |
| `/home/hero-street.webp` | `media/derived/首页主视觉.webp` | 是（源 `designs/pages/home/v02.../assets/主视觉.png`） |
| `/samples/demo-night.jpg` | `media/derived/夜景演示原图.jpg` | 是（降质废片演示版） |

**变更流程**：
1. 改源文件（`资产仓库/` 内）
2. 同步到 `代码仓库/web/public/` 对应路径
3. 更新 `manifests/运行时映射.json` 的 sha256
4. 跑 `npm run build` + 资源 404 检查

## 5. 命名规范（摘要，全文见 AGENTS.md §6）

- **资产文件用中文**（可读性优先）：`总索引.md`、`封面.webp`、`提示词.md`、`咖啡午后.jpg`。
- **目录与技术标识用英文 kebab-case**：`media/generated/`、`templates/film-daily/`、`vNN-YYYYMMDD-<intent>`、`web/public/` 运行时路径、第三方 Skills、`index.html`。
- 版本目录：`vNN-YYYYMMDD-<intent>`，禁止 `最终版/new/old/final/copy`
- 状态枚举：`concept | review | approved | superseded | archived`
- 页面素材：`<page>-<slot>-vNN-YYYYMMDD-<variant>.<ext>`
- 预览图：`preview-desktop@2x.webp`、`preview-tablet@2x.webp`、`preview-mobile@2x.webp`
