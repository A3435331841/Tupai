## 2. 状态与分类速览

**六态生命周期**（状态在目录分区、清单字段、版本说明三处同步）：

| 状态 | 枚举值 | 目录分区 | 含义 |
|---|---|---|---|
| 草稿 | `draft` | `草稿/` | 探索中，未参与决策 |
| 评审 | `review` | `评审/` | 已成形，待拍板 |
| 在用 | `approved` | `在用/` | 当前采纳，单元内唯一 |
| 历史 | `superseded` | `历史/` | 曾被采纳，后被取代 |
| 放弃 | `discarded` | `放弃/` | 未选中/被否决 |
| 留档 | `archived` | `留档/` | 过程证据（截图/裁切/副本），非设计决策 |

**六维标签**（正交维度用标签，不建目录）：用途 / 风格 / 场景 / 页面 / 主题 / 合规。受控词表见 `90-元数据/标签词表.json`。

## 3. 运行时映射（关键）

代码通过 `代码仓库/web/public/<path>` 引用资源，其源文件由 `90-元数据/运行时映射.json` 追溯：

| 运行时路径 | 源文件 | 派生 |
|---|---|---|
| `/brand/logo-horizontal.svg` | `10-品牌资产/标志/在用/标志-横版.svg` | 否 |
| `/brand/logo-icon.svg` | `10-品牌资产/标志/在用/标志-图标.svg` | 否 |
| `/templates/<id>.webp` | `60-模板资产/<id>/封面.webp` | 是（压缩版） |
| `/gallery/*.jpg` | `40-图片资产/真实授权/*.jpg` | 否 |
| `/gallery/*.png` | `40-图片资产/AI生成/在用/*.png` | 否 |
| `/home/hero-street.webp` | `40-图片资产/派生加工/首页主视觉.webp` | 是 |
| `/samples/demo-night.jpg` | `40-图片资产/派生加工/夜景演示原图.jpg` | 是（降质废片演示版） |

**变更流程**：① 改源（`资产仓库/` 内）→ ② 同步到 `代码仓库/web/public/` → ③ 更新 `90-元数据/运行时映射.json` 的 `source_path`/sha256 → ④ `npm run build` + 资源 404 检查。`public/` 路径一律不动。

## 5. 命名规范摘要

- **目录与文件均用中文**（可读性优先）；仅 `<模板id>/`、版本前缀 `vNN-YYYYMMDD`、资产 `id`（英文 slug）、扩展名、`web/public/` 运行时路径保留英文。
- 版本目录：`vNN-YYYYMMDD-<中文意图>`，`v00-` 专用于未采纳方案；**禁止** 最终版/新版/old/final/copy。
- 状态分区：`在用/`、`草稿/`、`评审/`、`历史/`、`放弃/`、`留档/`。
- 当前版本由页面 `索引.md` + `status=approved`（单元内唯一）表达，不改名为 final、不复制 current。
- 完整规则见 `docs/13` 与本地 `AGENTS.md §6`。
