# 品牌标志资产清单（brand）

> 依据 [docs/04-资产与数据.md](../../docs/04-资产与数据.md) §1 规则：任何入库资产必须有来源与协议记录。
> 定稿：A1「咬合 TP」 · 配色「暖阳」 · 楷体字标 · 2026-11-17 用户拍板。

## 1. 来源与协议

- **来源**：图派自主设计。图形 A1 由用户提供的 TP 字母标参考图启发重新绘制（未复制任何受保护标志）；配色与字标由本项目自定。
- **协议**：本项目自有资产，随项目 MIT 许可使用。参考图仅作风格方向启发，未复制其像素或商业外观。
- **字体说明**：中文「图派 / 废片变作品」使用系统**楷体**字体栈（STKaiti / KaiTi / 楷体 / Kaiti SC），非内嵌字体文件；英文 `TuPai` 使用 Georgia 斜体衬线（系统字体）。两款均为系统/通用字体，无分发授权问题；字标在 SVG 中以 `<text>` + 字体栈实现，缺失楷体时回退 serif。

## 2. 文件清单与用途

命名规范：kebab-case，小写英文 + 连字符；用途后缀明确。

| 文件 | 规格 (viewBox) | 用途 |
|---|---|---|
| `logo-icon.svg` | 100×100 | 纯图标：favicon、App 角标、社交头像 |
| `logo-horizontal.svg` | 460×130 | 横版主标（浅色底）：导航栏、页眉、邮件签名 |
| `logo-horizontal-dark.svg` | 460×130 | 横版反白（深色底）：深色背景、反色场景 |
| `logo-stacked.svg` | 220×250 | 竖版组合：启动页、名片、竖版物料 |

## 3. 设计规范

- **配色**（暖阳）：
  - 主色（橙 T）`#EA580C`
  - 深色（P / 字标）`#1C1917`
  - 深色底反白 `#F5F1EA` / 辅助灰 `#B9AFA2`
- **图形**：橙色 T 与炭黑 P 共用顶部横笔，两条竖笔底部收成尖角，构成「TP」咬合标志。
- **字体**：
  - 中文 `font-family: STKaiti, KaiTi, 楷体, Kaiti SC, BiauKai, DFKai-SB, serif`，粗体
  - 英文 `font-family: Georgia, 'Times New Roman', serif`，斜体
- **使用**：最小尺寸图标 ≥24px；四周留白 ≥ 图标高度 1/4；浅底用深色字标、深底用反白版；禁止拉伸、改色、加外发光（单色场景除外）。
