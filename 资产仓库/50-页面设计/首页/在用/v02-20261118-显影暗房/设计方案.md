## 🖱️ 画廊点选交互优化（2026-11-18 · 最新）

用户要求从真实操作体验优化：点图立即居中放大、点其他图自然切换、关闭恢复、悬停/选中/切换/返回清晰、快速连点不错乱、多屏适配。已重写 `画廊演示.html` 与首页 `index.html` 的画廊交互，采用**浏览 / 悬停 / 选中**三态状态机：

| 状态 | 表现 |
|---|---|
| 浏览态 | 自动循环滚动；悬停卡轻微放大 + 提亮 + z 提升；鼠标 X/Y 视差位移与 3D 翻转 |
| 选中态 | 点击任意卡：该卡平滑归位到正中央、放大到 1.2×、最亮最清晰、陶土橙描边、z=200 置顶；背景径向渐变压暗；显示标题/描述/「用这张做同款」按钮与右上关闭 ×；自动滚动暂停 |
| 切换 | 选中态点其他卡 / 上一下一按钮 / 方向键 → 平滑切换到新卡并保持选中 |
| 关闭 | 再点同一张 / 点空白 / 关闭按钮 / Esc → 恢复浏览态与自动滚动 |

**关键技术**：
- `pointerdown` 瞬间锁定命中目标（`downHit`），`pointerup` 用它决策，避免选中卡放大导致 `elementFromPoint` 命中漂移——这是快速连点稳定的核心。
- 拖拽阈值 4px 区分点击/拖拽；拖拽中自动退出选中态。
- 选中归位用 `offset += (targetOffset-offset)*0.14` 平滑插值，快速连点会追随最新目标；`targetOffset` 基于点击瞬间的循环最短距离计算。
- 选中态视差归零（避免居中后被鼠标推偏）；蒙层用径向渐变融入背景。

**验收**：Playwright 实测快速连点同一卡状态序列 `[0,null,0,null]`（严格交替、零错乱）；点击→居中 scale 1.2 / z 200 / x≈0；点其他卡切换、关闭按钮、Esc、同卡再点关闭全部正常；首页桌面/移动均 20 图加载、无 JS 错误、零横向溢出。

## 2. 视觉风格：暗房显影 · Film Lab

一句话气质：**温暖的胶片暗房里，一张照片正在被光"洗"出来。**

- **情绪**：温暖、克制、有手感、带一点"魔法时刻"的惊喜——不做冷冰冰的 AI 工具，做"帮你把照片救回来"的伙伴。
- **视觉母题**：显影（灰→暖的分割与光扫）、取景框（四角）、胶片颗粒（全局 3.5% 噪点 overlay）、编辑感排版（衬线英文 + 无衬线中文）。
- **差异点**：同类 AI 出图站多用深色科技风；图派用暖米白编辑风 + 一处陶土橙，在信息流里反而更醒目、更亲和，也贴合"生活照改造"的场景。

### 2.1 色彩规范

| Token | 色值 | 用途 |
|---|---|---|
| `--bg` | `#faf7f2` | 主背景（暖米白，沿用既有） |
| `--surface` | `#ffffff` | 卡片 / 浮层 |
| `--surface-2` | `#f1eae0` | 次级面 / chip / 输入底 |
| `--ink` | `#241c16` | 主文字 / 图标线（深墨棕） |
| `--ink-soft` | `#6b5d4e` | 次要文字 |
| `--accent` | `#c0562f` | 品牌主色 / CTA（由原 `#b4552d` 微调提亮，对比度更佳） |
| `--accent-strong` | `#a84420` | 按钮 hover |
| `--glow` | `#e8a866` | 显影金 / 高光 / 渐变 |
| `--line` | `#e4d9ca` | 描边 / 分隔 |
| `--ok` | `#2f7d5b` | 成功 / 卖点勾选 |

> 涨红跌绿等金融约定与本产品无关，全站仅用上述暖色系。对比度：正文 `#241c16` on `#faf7f2` ≈ 14:1，主按钮白字 on `#c0562f` ≈ 4.6:1，均达 AA。

### 2.2 字体规范

- **中文**：`"PingFang SC","Hiragino Sans GB","Microsoft YaHei","Noto Sans SC",sans-serif`
- **英文点缀 / 数字**：`Georgia, serif` 斜体（品牌英文 TuPai、序号、ratio 标签），制造编辑设计感
- **层级**：H1 `clamp(40,5.2vw,68)` / H2 `clamp(30,3.6vw,46)` / 正文 `16-17` / 辅助 `12-14`；标题字重 800–850、字距 `-.03~-0.045em`；正文行高 1.6。

**导航**：首页/创作台/资产库/社区为一级；"隐私与 AI" 次级；"开始创作"为常驻主 CTA。移动端折叠为汉堡菜单。

## 4. 动效思路

动效服务于"显影"叙事，克制且有目的，全部遵循 `prefers-reduced-motion`：

| 动效 | 位置 | 思路 |
|---|---|---|
| **显影对比滑块** | Hero | 拖动分界线，左灰暗废片 ↔ 右暖色作品实时揭示——把核心功能变成第一眼可玩的交互（`pointer` 事件 + `clip-path`） |
| 显影扫光 | Hero 对比图 / Logo | 一道暖光周期性扫过，暗示"正在显影"，循环但低频（4.5s） |
| 打字机 | 自动优化提示词演示 | 候选提示词逐字打出、停顿、切换，具象"AI 在帮你写提示词" |
| 滚动进场 | 各 section | `IntersectionObserver` 触发淡入上移，错峰 70ms，弱化"长页面"疲劳 |
| 卡片微交互 | 模板卡 / 步骤卡 | hover 上浮 + 图片缓慢放大 + "做同款"按钮滑入，提示可点击 |
| 按钮反馈 | 全局 CTA | 磁吸式上浮 + 阴影加深 + 箭头右移 |

所有动效在 `prefers-reduced-motion: reduce` 下自动降级为静态。

## 5. 与现有项目的衔接方案

原型 `index.html` 是**自包含可直接预览**的设计稿；落地到 React 项目按以下最小化改动，不改变任何业务逻辑与 API：

1. **色板**：`src/globals.css` 中 `--site-*` 变量按第 2.1 节更新（`--site-accent: #c0562f` 等），shadcn 变量已映射到 `site-*`，改一处全站生效。
2. **Logo**：`src/App.tsx` 第 17–19 行的"派"字方块替换为 `<img src="/assets/logo-icon.svg">` + 横版字标；页脚同理用竖版。
3. **首页内容**：将 `pages/Home.tsx` 的 hero 区替换为原型的 Hero（含对比滑块组件），三步/模板/卖点区按原型文案重排；模板数据继续走 `api.templates()`，封面字段 `apiUrl(t.cover_url)` 保持不变。
4. **对比滑块**：封装为 `components/DevelopCompare.tsx`，props 接收 `beforeUrl/afterUrl`；与创作台结果页 `CompareSlider` 合并为同一组件，全站一致。
5. **路由**：原型按钮已带 `data-route`，接入时挂 `window.__TUPAI_ROUTER__.navigate` → 现有 `useRoute()` 的 `navigate`；参数沿用现有约定：`/studio?demo=night&template=night-bright`、`/studio?demo=text`、`/studio?template=<id>`，保证一键试玩/做同款照常工作。
6. **素材**：`assets/` 图片放入 `web/public/`，模板封面可继续用仓库 `test-images` 或本次生成的 3 张（AI 示意，需带"AI 示意"角标，符合 05 文档合规要求）。

> 落地原则：**只换"皮"，不动"骨"**——所有 API 契约、状态机、隐私与 AI 标识逻辑原样保留。
