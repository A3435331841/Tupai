图派首页 · 三套整合方案对比 保留拉拽交互

基于当前实现（显影相框首页 + 可拖动修前修后对比）与两份设计稿（Codex 杂志策展 / Light-theme 卡片克制）整合。三套方案都保留可拖动的修前修后对比，差异在整体布局、文案密度与视觉气质。

共同原则：文案大幅精简（删勾选清单、删能力条、删打字机大段、删三张说明卡）；用大图、留白、01/02/03 序号、细线分隔、楷体标题替代长段落；按钮收敛为「开始创作 + 一键试玩」两个。你选一套后我再实施。
A

杂志策展

最贴近 Codex 设计稿 · 视觉冲击最强
图派　首页 / 创作台 / 资产库 / 社区　　登录
01 上传照片02 选择灵感03 收获作品
55/45 不对称双栏宋体大字五图书架
风格差异

首屏左文右图，宋体大标题占三行；右侧一张带相纸边框的大作品图，叠一张可拖动的原图/作品对比小卡。模板五张横排、首张略大。工作流用 01/02/03 一行细线分隔。

优点最像摄影杂志，作品是绝对主角；文字最少、留白最多、视觉最抓人。
缺点功能信息弱化，"游客免登录/隐私/AI 标识"等信任点被压到极小的微文案。
适用评委看视觉、比赛演示首屏抓眼球；追求"作品集"气质。
B

卡片克制

最贴近 Light-theme 预览 · 折中稳妥
图派　首页 / 创作台 / 资产库 / 社区　　登录
01 上传02 选方向03 带走
大圆角卡片右侧步骤卡信息完整
风格差异

首屏收在一张大圆角浅卡里：左侧主张 + 精简文案 + 双按钮，右侧一张"三步就能出片"步骤卡。模板五张卡，图在上、名称在下。对比滑块放在步骤卡下方或创作台入口。

优点信息最完整、结构最稳；改动量小，和现有组件/后台风格一致，落地最快。
缺点视觉冲击弱于 A，仍有"卡片后台感"；文案虽精简但仍多于 A。
适用偏功能型演示、需要把隐私/步骤讲清楚；追求稳妥低风险。
C

显影暗房 我推荐

融合双方优点 · 兼顾视觉与交互记忆点
图派　首页 / 创作台 / 资产库 / 社区　　登录
01 放入照片02 选择方向03 收获作品
全幅可拖动显影对比极简文案动效记忆点
风格差异

取 A 的大图双栏，但把对比做成整幅可拖动的显影图：拖动分界线时一道暖光扫过，灰片实时变作品——把产品核心动作变成首屏主角。左侧只留两行标题 + 一句副标题 + 双按钮。模板五图横排，底部 01/02/03。

优点兼具 A 的视觉冲击和当前版的拉拽乐趣；显影动效是独特记忆点，文案最精简。
缺点交互实现比 A/B 稍复杂；需确保拖动在手机上也顺滑。
适用想要"既好看又能玩"、突出产品差异化；比赛演示需要记忆点。
