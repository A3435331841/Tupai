# 资产库概念图提示词

Use case: ui-mockup  
Asset type: high-fidelity desktop photo archive concept art  
Primary request: 为“图派 TuPai”设计私人影像档案页，让生成作品、原图、Skills 配方和画册像一套精美的个人摄影集，而不是网盘文件列表。  
Style: warm ivory paper, independent photo archive, editorial catalog, premium web app, quiet luxury but approachable, real editorial photography.  
Palette: #F7F1E7 paper, #211C17 ink, #BB5834 terracotta accent, #667A64 moss labels, #FFFDF8 cards.  
Composition: 16:10 desktop, straight-on, 1440 px. Top navigation same as TuPai. Page title “我的影像档案”, subtitle “原图私密 · 结果可分享 · 配方可带走”. Right actions 搜索, 资产, 画册, 去创作. Slim stats row 24 件作品 / 7 套配方 / 3 本画册. Main asymmetric masonry gallery of eight editorial photographs with varied heights: night dinner, golden travel postcard, analog cafe portrait, rainy neon, monochrome magazine portrait, quiet studio portrait, food still life, seaside. Each card has a tiny date and template label. First large card is “雨夜之后” and includes a subtle hover action “再创作”. Right column features one beautiful open photo-book album “十一月 · 小城夜游” with ink caption and button “打开画册”; underneath a compact Skills recipe card with JSON and SKILL.md chips. Privacy annotation in moss green: “原图仅自己可见”.

Constraints: all Chinese labels clean and readable; no desktop file manager; no spreadsheet density; no generic admin sidebar; no browser chrome or device frame; no watermark; no gibberish; face images invented, no celebrity. 2K high fidelity.
