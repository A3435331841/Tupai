## 1. 产品定位

**一句话**：图派帮普通人把日常废片改成愿意发出去的作品——可以不公开原图，只发二次创作结果，并把用过的模板与提示词存成可复用、可分享的 Skills 技能包。

| 维度 | 内容 |
|---|---|
| 产品名 | 图派（TuPai） |
| 主用户 | 不善拍照、但要发朋友圈/小红书/社交的普通人 |
| 主场景 | 生活照、自拍、旅行随手拍、聚餐糊片的改造 |
| 核心价值 | 低门槛出片 + 原图可藏 + 配方可带走/可复用 |
| 差异点 | 生活照入口 × 可见可改的提示词 × Skills 可 fork |
| 不做成 | 下一个醒图滤镜库，或下一个 Civitai 模型站 |

**初心**：让拍照不好看的人，也能有别样的作品去发布——可以不发原图。

## 2. 三大能力与三期路线

| 能力 | 期次 | 内容 |
|---|---|---|
| 图片二次开发与改造（**AI 二次创作为核心**） | **一期** | 图片/文字/链接三入口、自动 prompt 优化、相似推荐预览、模板、模型替换、Skills 打包 |
| 图片导入与管理 | 二期 | 上传归档、检索、画册呈现（复用开源 flipbook 画册技能） |
| 社区 | 三期 | 分享作品/提示词/想法，可 fork 的 Skills，开放共创（类 DeepSeek Harness） |

一期只交付 AI 创作闭环；二期三期只留数据钩子，不做完整产品。

## 3. 一期主流程（MVP：图片或文字入口）

```
上传图片 或 输入文字（生成前可随时补/换底图） → 自动优化 prompt（中文摘要 + 候选）
→ 相似模板/Skills 推荐(带效果预览；无匹配给 5 模板兜底) → 套用模板/变体（可选）
→ 微调提示词·切换模型 → 生成作品(可换一批/再生成；刷新可恢复上次) → 下载成品 / 导出Skills
```

1. **进入创作区**：三种入口——上传图片 / 输入一句文字 / 粘贴链接（扩展项）。**MVP 只依赖前两种**。界面明确「结果可独立发布，原图可留私」；首页有内置样例一键试玩（样例废片 + 夜景提亮模板），未登录可走通。创作台 ready 阶段可补/换/移除底图。
2. **自动优化 prompt**：用户不需要会写提示词。图片 → 视觉理解自动产出优化后的提示词（2–4 条候选，每条带中文一句话摘要）；文字 → 自动扩写润色为可用出图提示词。支持「换一批候选」，保留当前底图。
3. **相似推荐 + 预览**：根据图片内容/文字意图，在模板与 Skills 库中检索相似项，展示封面、说明与匹配原因；用户可一键套用，也可在创作台手动选择模板。无匹配时返回 5 个模板兜底，不挡主路径。Skills 推荐带完整配方（负面词/模型/画幅/封面）。
4. **微调与生成**：提示词可编辑（中文摘要在上、英文提示词在高级编辑区）、模型可切换、不满意可换一批或再生成；结果与原图并排预览。任务元数据本地保存，刷新/重进可恢复上次作品或继续等待，避免配额白扣。
5. **带走**：下载成品（必须带 AI 生成标识，不提供无标识兜底）；导出 Skills（JSON / SKILL.md）；站内「我的配方」可随时套用保存过的配方。

**链接入口（一期扩展，非 MVP 依赖）**：粘贴抖音图文链接 → 站内直接解析出图片与文案 → 作为参考素材进入上述流程，无需用户借助外部工具。解析失败或视频链接 → 引导手动上传图片/文字（视频可截帧上传）。解析所得原内容**用后即焚，不落库、不传播**（合规边界见 [05-注意事项](05-注意事项.md)）。

## 4. 一期功能需求与验收

**MVP 定义：F1–F11、F13–F15 全部走通（图片或文字入口的完整闭环）。F12 链接解析为扩展项，尽力而为，不阻塞 MVP 验收。**

| # | 模块 | 需求 | 验收标准 |
|---|---|---|---|
| F1 | 首页 | 价值主张、开始创作、一键试玩 | 未登录可进入试玩 |
| F2 | 图片上传 | 单张上传，常见手机图片格式（含 HEIC 自动转 JPG，失败有引导），大小/格式校验，可清除重选；生成前可更换底图 | 失败有可读错误；有原图预览 |
| F3 | 文字输入 | 一句话描述即可开始创作（如「想要杂志风自拍」）；生成前可补底图 | 文字单独可走通全流程 |
| F4 | 自动 prompt 优化 | 图片→视觉理解出 2–4 条候选提示词+中文摘要；文字→扩写润色；可换一批 | 用户零提示词知识可判断/出片；失败可重试 |
| F5 | 相似推荐 + 预览 | 检索相似模板与 Skills，展示封面/说明/匹配原因；无匹配返回 5 模板兜底；Skills 带完整配方 | 推荐可一键套用；创作台可手动选模板；空匹配不挡主路径 |
| F6 | 模板库 | ≥5 个日常向模板：名称、封面示意、说明、默认提示词、文生图示意词、变体、特征标签 | 一点即填入；无图用示意词，有图切图生图；变体可选 |
| F7 | 提示词编辑 | 正/负面（可选），字数提示；中文摘要在上，英文提示词为高级编辑 | 改后可再生成 |
| F8 | 模型切换 | ≥2 个可选模型（带说明），选择写入任务与 Skills | 切换不丢当前提示词 |
| F9 | 生成任务 | 异步任务，排队/进行/成功/失败状态，失败重试；刷新/重进可恢复或继续，展示今日剩余额度 | 成功展示结果图；超时有明确文案；不因刷新丢结果 |
| F10 | 结果操作 | 下载、再生成、另存 Skills | 结果图与下载物必须带「AI 生成」标识；标识写入失败则拒绝下载 |
| F11 | Skills | 导出 JSON + SKILL.md；导入回填；站内「我的配方」列表；保存封面/template_id/选中候选标签 | 缺字段有校验提示；换底图换模型仍可生成；导入未知模型自动回默认 |
| F12 | 链接解析（扩展） | 抖音图文链接 → 站内解析出图片+文案 → 进入创作流程 | 尽力而为：失败有降级引导；原内容用后即焚；视频链接引导截帧上传 |
| F13 | 隐私 | 原图默认私密，无强制公开原图；链接解析内容不落库 | 全程可不公开原图完成下载 |
| F14 | 账号 | 游客可用全流程；登录仅为云端保存（可选） | 无登录不挡主路径 |
| F15 | 移动端 | 创作台主路径手机可用 | 手机浏览器走通主流程 |

**首批 5 个模板（融合版，2026-11-17 已定稿）**：胶片日常、夜景提亮（含雨夜霓虹变体）、清透人像、旅行明信片、杂志封面。每个模板有 open-image-prompts 风格卡做视觉语法支撑（映射见 `资产仓库/skills-source/sources.md`），提示词全部自写。

**体验成功标准**：用户用自己的一张日常废片，约 10 分钟内得到「愿意发」的一张，且全程不被迫公开原图。

**首批数据来源**：模板提示词从 GitHub 等平台公开的图片二次创作 Skills 提炼；测试底图用公开图片数据（详见 [04-资产与数据](04-资产与数据.md)）。

## 5. Skills 技能包（产品规格）

### 5.1 站内配方 JSON（tupai-skill-v1）

```json
{
  "format": "tupai-skill",
  "version": 1,
  "title": "夜景提亮·人像",
  "prompt": "...",
  "negative_prompt": "...",
  "model": "provider/model-id",
  "template_id": "night-portrait",
  "params": { "aspect": "3:4" },
  "notes": "适合室内暗光自拍",
  "cover_url": "/api/v1/assets/a_xxx/content",
  "created_at": "2026-11-17T00:00:00+08:00"
}
```

- 字段可增不可改语义；导入校验 format/version 后回填创作台。
- **不内嵌他人原图像素**；预览用单独可选 cover URL（本站私有资产，仅同会话可读）；导入后提示上传「自己的」底图。
- 保存时记录 `template_id`、用户选中的候选风格标签与当前结果封面；站内「我的配方」可列出并一键套用。

### 5.2 Qoder SKILL.md 导出

同一配方可一键导出为 Agent Skills 目录格式（SKILL.md + 可选参考文件），安装进 Qoder 等 Agent 工具执行。形成「作品 → 配方 → Agent 技能」沉淀链条。

## 6. 二期需求：图片导入与管理（个人影像资产库 + 画册）

> 状态：详细策划，**未实现**。一期已预留 `kind/visibility` 等数据钩子；二期在其上扩展，不改一期语义。

### 6.1 定位

从「单次创作工具」升级为「**个人影像资产库**」：让用户把原图、生成图、提示词、Skills 归档起来，能检索、能复用、能成册讲故事。**不是网盘**——不做通用文件存储、不做外链图床、不做公开分享原图。隐私底线延续一期：original 全程 private，任何呈现/分享只触及 result + 元数据。

### 6.2 主流程

```
导入（手动上传 / 一期作品自动归档 / 拾影链接导入）
→ 资产库（归档·打标·多维检索·详情）
→ 复用（从任一资产带配方+底图发起二次创作）
→ 画册（选资产集 → flipbook 生成翻页书 → 预览 / 导出 / 部署）
```

### 6.3 功能清单与验收

| # | 模块 | 需求 | 验收标准 |
|---|---|---|---|
| P2-F1 | 账号与登录 | 可选登录保护「我的资产」，支持跨设备；游客一期数据可绑定迁移 | 登录态资产跨设备可见；不登录不挡浏览公开内容；游客→登录迁移不丢数据；**明示游客数据易失（清缓存/换设备即丢），引导尽早登录或导出保存** |
| P2-F2 | 资产归档 | 一期 original/result 自动入库；手动上传归档；记录 kind/visibility/tags/来源/时间 | 上传即归档且默认 private；元数据完整可查；**自动继承一期 optimize 标签、可选 AI 补标，免用户手动打标** |
| P2-F3 | 多维检索 | 按标签/类型/时间/关键词组合筛选，缩略图网格 | 组合筛选可用；空态有引导；百张级响应 ≤1s |
| P2-F4 | 对话检索（增强） | 自然语言找图（如「去年海边的夜景」），参考 album-ai | 返回相关资产 Top-N；无匹配降级关键词检索；**不阻塞主路径** |
| P2-F5 | 资产详情 | 大图 + 元数据 + 所用配方 + 来源；从详情发起再创作 | 一键带「配方+底图」进创作台，参数不丢 |
| P2-F6 | 画册生成 | 选资产集 → 复用 flipbook（MIT）3D 翻页书；模板可选（2D/3D/Card 等） | 生成可翻页画册；保留 MIT 版权声明；只喂 result |
| P2-F7 | 画册导出/分享 | **一键生成只读分享链接**（unlisted，无需登录即可看，可撤回/可设有效期）；另支持导出静态站 zip/部署子路径 | 普通用户零技术门槛即可发给朋友；分享只含 result，隐私走查无 original 泄露；撤回后链接立即失效 |
| P2-F8 | 链接导入（拾影配合） | 文档引导「拾影下载→选图→上传」；评估浏览器调拾影 localhost API（进程隔离） | 引导顺畅；**不复制 GPL 代码**；公开参赛站不依赖此路径 |
| P2-F9 | 批量管理 | 多选 / 批量打标 / 批量入册 / 批量删除 | 批量操作有确认；**删除先入回收站（宽限期内可恢复），非一刀切真删** |
| P2-F10 | 存储与配额 | 每用户存储上限/张数配额；超限可读提示 | 配额可见；超限不丢已有数据；清理入口明确；**明示是否收费与满了如何自主清理** |
| P2-F11 | 隐私延续 | original 全程 private；画册/分享只触及 result+元数据；删除分层 | 跨用户取不到他人 original（404）；**回收站宽限期内仍 private、可恢复；彻底删除后不可访问** |
| P2-F12 | 移动端 | 资产库 / 详情 / 画册手机可用 | 移动主路径走通，无横向溢出 |
| P2-F13 | 升级引导与跨期兼容 | 一期用户平滑升级：旧作可见、旧配方可用；新功能有引导 | **一期导出的 tupai-skill v1 配方二期仍可导入**；一期游客作品有留存提示与迁移入口；升级不丢已有 Skills |

### 6.4 数据与规格增量

- **Asset 扩展**：在一期 `id/owner/kind/storage_key/visibility/width/height` 上增 `tags[]/source/album_ids[]/created_at/thumb_key/deleted_at`；original 仍默认 private；`deleted_at` 支持回收站软删（宽限期内可恢复，期满彻底删除）。
- **Album（画册）**：`id/owner/title/cover_asset_id/item_ids[]/template_id/visibility(private|unlisted)/render_status/share_token/share_expires_at`；分享 token 只读、可撤回。
- **User（登录态）**：`id/auth_subject/display_name/storage_quota/used`；游客以会话标识，登录后绑定。
- 检索一期沿用标签加权匹配；对话检索为可选增强（向量/LLM 排序），不引入则关键词兜底。

### 6.5 体验成功标准

用户能把一期至今的作品归成**一本可分享的画册**，全程不公开原图；用关键词或一句话在 10 秒内找到目标图；从任一旧作一键发起再创作。

### 6.6 边界与不做

不做通用网盘/外链图床/视频存储/RAW 精修/多人协作编辑；对话检索与拾影 localhost 桥接均为**增强项**，不阻塞二期验收。

## 7. 三期需求：社区与共创

> 状态：详细策划，**未实现**。依赖二期账号体系与资产库。隐私底线：公开的是 **result + 配方**，original 永不公开；fork 者用**自己的**底图或纯文字，不携带他人底图。

### 7.1 定位

从「个人资产库」到「**可 fork 的共创社区**」：作品连同完整配方公开，陌生人可一键套自己的底图再做一张，形成可追溯的二次创作链条；轻量共创任务让多人围绕同一主题参与。呼应 Qoder 生态「作品 → 配方 → Agent 技能」的沉淀与复用。

### 7.2 主流程

```
发布（显式选择 result+配方 → 审核 → 公开）
→ 发现（瀑布流 / 标签 / 搜索 / 作者主页）
→ 一键 fork（继承配方 + 自己底图或纯文字 → 生成）
→ 再发布（记录 lineage：parent_work / parent_skill）
共创支线：发起公开任务 → 多人提交 → 任务页作品链
```

### 7.3 功能清单与验收

| # | 模块 | 需求 | 验收标准 |
|---|---|---|---|
| P3-F1 | 公开发布 | 显式选择发布 result+配方；发布前隐私确认；**可选「允许他人 fork」开关；含真人人脸时谨慎提示；发布后可撤回** | 默认 private；发布需显式动作+确认+审核 gate；关闭 fork 后他人只能看不能套；撤回后停止新 fork |
| P3-F2 | 作品页 | **效果优先**：大图+一键做同款为主，完整配方（prompt/params/model）折叠可展开；作者+lineage | 新手不读 prompt 也能一键做同款；配方可展开可读；AI 标识在位 |
| P3-F3 | 发现页 | 瀑布流 + 标签筛选 + 排序（最新/热门），即梦式「做同款」入口 | 首屏即达作品；做同款一键进 fork |
| P3-F4 | 一键 fork | 继承配方，用自己底图**或纯文字**生成；记录 lineage；**原作者署名沿 lineage 保留** | 不携带他人 original 像素；无底图也能 fork（文生图）；lineage ≥2 层且每层可见原作者 |
| P3-F5 | 作者主页 | 公开作品集 / 配方 / 被 fork 数 | 仅展示公开内容；私有资产不可见 |
| P3-F6 | 互动 | 评论 / 点赞，登录可参与，防刷；**作者可管理自己作品下的评论（删除/折叠恶意）** | 速率限制生效；可删自己评论；作者可清理自己作品下恶意评论 |
| P3-F7 | 共创任务 | 发起公开任务（主题/约束）→ 参与提交 → 任务页作品链 | 任务可创建/参与/关闭；提交关联 lineage |
| P3-F8 | 搜索 | 作品 / 配方 / 作者 / 标签全文检索 | 多维搜索可用；空态友好 |
| P3-F9 | 审核与安全 | 发布前 AI+规则审核（NSFW/侵权/真人肖像）；举报/下架；**被误判者申诉通道** | 违规拦截；举报可用；下架真删公开副本；误判可申诉复核恢复 |
| P3-F10 | 通知 | fork / 评论 / 任务动态通知 | 通知可达、可关闭 |
| P3-F11 | 防滥用 | 发布/评论/fork/社区生成速率限制与配额 | 防刷不击穿主路径；配额可读 |
| P3-F12 | 隐私与肖像 | 公开作品带 AI 标识；真人肖像提示；original 永不公开 | 隐私走查全过；被 fork 者底图自传 |
| P3-F13 | 移动端 | 社区浏览 / 作品页 / fork 手机可用 | 移动主路径走通 |
| P3-F14 | 数据可携带 | 导出自己的全部公开作品+配方；注销删除 | 导出完整；注销后公开内容真删 |
| P3-F15 | 撤回与署名控制 | 已发布作品可撤回（停止新 fork）；fork 链保留原作者署名 | 撤回后新 fork 被拒；已 fork 作品保留但标注「来源已撤回」；署名沿链不可抹除 |

### 7.4 数据与规格增量

- **Work（公开作品）**：`id/owner/result_asset_id/skill_snapshot/title/tags/visibility(public)/lineage{parent_work_id,parent_skill_id}/status(pending|published|removed|withdrawn)/allow_fork/created_at`；`allow_fork` 控制他人可否套用，`withdrawn` 停止新 fork。
- **ForkLineage**：`work_id/parent_work_id/parent_skill_id/depth/author_credit`；fork 只继承配方快照，不复制他人底图；`author_credit` 沿链保留原作者署名。
- **Comment / Like**：`id/work_id/owner/body|/created_at/hidden_by_author`；速率限制；作者可折叠/删除自己作品下评论。
- **Task / Submission**：`task{id/owner/theme/constraints/status}`、`submission{id/task_id/work_id/owner}`。
- **Report / Notification**：举报与通知队列。
- **Profile**：`user_id/display_name/bio/public_counts`。

### 7.5 体验成功标准

一个作品被陌生人 fork 并再发布，形成 **≥2 层 lineage**；社区全程**零 original 泄露**；违规内容能被拦截或下架。

### 7.6 边界与不做

不做私信/关注 feed 等重社交、不做付费分成（后期）、不做模型训练/LoRA、不做 NSFW 生态；共创是轻量任务式，非完整论坛。
