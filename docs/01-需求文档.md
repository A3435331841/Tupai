# 图派 · 需求文档

> 版本 v3.1 · 2026-11-17 · 本文只回答「做什么」，不写技术实现与参赛策略。
> v3.1 变更：一期主入口收敛为「图片/文字 → 自动优化 prompt → 相似推荐预览」；抖音链接解析降为一期扩展项，MVP 不依赖。
> 实现见 [02-开发文档](02-开发文档.md)，赛务见 [06-参赛交付](06-参赛交付.md)。

## 1. 产品定位

**一句话**：图派帮普通人把日常废片改成愿意发出去的作品——可以不公开原图，只发二次创作结果，并把用过的模板与提示词存成可复用、可分享的 Skills 技能包。

| 维度 | 内容 |
|---|---|
| 产品名 | 图派（TuPai） |
| 主用户 | 不善拍照、但要发朋友圈/小红书/社交的普通人 |
| 主场景 | 生活照、自拍、旅行随手拍、聚餐糊片的改造 |
| 核心价值 | 低门槛出片 + 原图可藏 + 配方可带走/可复用 |
| 差异点 | 生活照入口 × 可见可改的提示词 × Skills 可 fork |
| 不做成 | 下一个醒图滤镜库，或下一个 Civitai 模型站 |

**初心**：让拍照不好看的人，也能有别样的作品去发布——可以不发原图。

## 2. 三大能力与三期路线

| 能力 | 期次 | 内容 |
|---|---|---|
| 图片二次开发与改造（**AI 二次创作为核心**） | **一期** | 图片/文字/链接三入口、自动 prompt 优化、相似推荐预览、模板、模型替换、Skills 打包 |
| 图片导入与管理 | 二期 | 上传归档、检索、画册呈现（复用开源 flipbook 画册技能） |
| 社区 | 三期 | 分享作品/提示词/想法，可 fork 的 Skills，开放共创（类 DeepSeek Harness） |

一期只交付 AI 创作闭环；二期三期只留数据钩子，不做完整产品。

## 3. 一期主流程（MVP：图片或文字入口）

```
上传图片 或 输入文字（生成前可随时补/换底图） → 自动优化 prompt（中文摘要 + 候选）
→ 相似模板/Skills 推荐(带效果预览；无匹配给 5 模板兜底) → 套用模板/变体（可选）
→ 微调提示词·切换模型 → 生成作品(可换一批/再生成；刷新可恢复上次) → 下载成品 / 导出Skills
```

1. **进入创作区**：三种入口——上传图片 / 输入一句文字 / 粘贴链接（扩展项）。**MVP 只依赖前两种**。界面明确「结果可独立发布，原图可留私」；首页有内置样例一键试玩（样例废片 + 夜景提亮模板），未登录可走通。创作台 ready 阶段可补/换/移除底图。
2. **自动优化 prompt**：用户不需要会写提示词。图片 → 视觉理解自动产出优化后的提示词（2–4 条候选，每条带中文一句话摘要）；文字 → 自动扩写润色为可用出图提示词。支持「换一批候选」，保留当前底图。
3. **相似推荐 + 预览**：根据图片内容/文字意图，在模板与 Skills 库中检索相似项，展示封面、说明与匹配原因；用户可一键套用，也可在创作台手动选择模板。无匹配时返回 5 个模板兜底，不挡主路径。Skills 推荐带完整配方（负面词/模型/画幅/封面）。
4. **微调与生成**：提示词可编辑（中文摘要在上、英文提示词在高级编辑区）、模型可切换、不满意可换一批或再生成；结果与原图并排预览。任务元数据本地保存，刷新/重进可恢复上次作品或继续等待，避免配额白扣。
5. **带走**：下载成品（必须带 AI 生成标识，不提供无标识兜底）；导出 Skills（JSON / SKILL.md）；站内「我的配方」可随时套用保存过的配方。

**链接入口（一期扩展，非 MVP 依赖）**：粘贴抖音图文链接 → 站内直接解析出图片与文案 → 作为参考素材进入上述流程，无需用户借助外部工具。解析失败或视频链接 → 引导手动上传图片/文字（视频可截帧上传）。解析所得原内容**用后即焚，不落库、不传播**（合规边界见 [05-注意事项](05-注意事项.md)）。

## 4. 一期功能需求与验收

**MVP 定义：F1–F11、F13–F15 全部走通（图片或文字入口的完整闭环）。F12 链接解析为扩展项，尽力而为，不阻塞 MVP 验收。**

| # | 模块 | 需求 | 验收标准 |
|---|---|---|---|
| F1 | 首页 | 价值主张、开始创作、一键试玩 | 未登录可进入试玩 |
| F2 | 图片上传 | 单张上传，常见手机图片格式（含 HEIC 自动转 JPG，失败有引导），大小/格式校验，可清除重选；生成前可更换底图 | 失败有可读错误；有原图预览 |
| F3 | 文字输入 | 一句话描述即可开始创作（如「想要杂志风自拍」）；生成前可补底图 | 文字单独可走通全流程 |
| F4 | 自动 prompt 优化 | 图片→视觉理解出 2–4 条候选提示词+中文摘要；文字→扩写润色；可换一批 | 用户零提示词知识可判断/出片；失败可重试 |
| F5 | 相似推荐 + 预览 | 检索相似模板与 Skills，展示封面/说明/匹配原因；无匹配返回 5 模板兜底；Skills 带完整配方 | 推荐可一键套用；创作台可手动选模板；空匹配不挡主路径 |
| F6 | 模板库 | ≥5 个日常向模板：名称、封面示意、说明、默认提示词、文生图示意词、变体、特征标签 | 一点即填入；无图用示意词，有图切图生图；变体可选 |
| F7 | 提示词编辑 | 正/负面（可选），字数提示；中文摘要在上，英文提示词为高级编辑 | 改后可再生成 |
| F8 | 模型切换 | ≥2 个可选模型（带说明），选择写入任务与 Skills | 切换不丢当前提示词 |
| F9 | 生成任务 | 异步任务，排队/进行/成功/失败状态，失败重试；刷新/重进可恢复或继续，展示今日剩余额度 | 成功展示结果图；超时有明确文案；不因刷新丢结果 |
| F10 | 结果操作 | 下载、再生成、另存 Skills | 结果图与下载物必须带「AI 生成」标识；标识写入失败则拒绝下载 |
| F11 | Skills | 导出 JSON + SKILL.md；导入回填；站内「我的配方」列表；保存封面/template_id/选中候选标签 | 缺字段有校验提示；换底图换模型仍可生成；导入未知模型自动回默认 |
| F12 | 链接解析（扩展） | 抖音图文链接 → 站内解析出图片+文案 → 进入创作流程 | 尽力而为：失败有降级引导；原内容用后即焚；视频链接引导截帧上传 |
| F13 | 隐私 | 原图默认私密，无强制公开原图；链接解析内容不落库 | 全程可不公开原图完成下载 |
| F14 | 账号 | 游客可用全流程；登录仅为云端保存（可选） | 无登录不挡主路径 |
| F15 | 移动端 | 创作台主路径手机可用 | 手机浏览器走通主流程 |

**首批 5 个模板（融合版，2026-11-17 已定稿）**：胶片日常、夜景提亮（含雨夜霓虹变体）、清透人像、旅行明信片、杂志封面。每个模板有 open-image-prompts 风格卡做视觉语法支撑（映射见 `资产仓库/skills-source/sources.md`），提示词全部自写。

**体验成功标准**：用户用自己的一张日常废片，约 10 分钟内得到「愿意发」的一张，且全程不被迫公开原图。

**首批数据来源**：模板提示词从 GitHub 等平台公开的图片二次创作 Skills 提炼；测试底图用公开图片数据（详见 [04-资产与数据](04-资产与数据.md)）。

## 5. Skills 技能包（产品规格）

### 5.1 站内配方 JSON（tupai-skill-v1）

```json
{
  "format": "tupai-skill",
  "version": 1,
  "title": "夜景提亮·人像",
  "prompt": "...",
  "negative_prompt": "...",
  "model": "provider/model-id",
  "template_id": "night-portrait",
  "params": { "aspect": "3:4" },
  "notes": "适合室内暗光自拍",
  "cover_url": "/api/v1/assets/a_xxx/content",
  "created_at": "2026-11-17T00:00:00+08:00"
}
```

- 字段可增不可改语义；导入校验 format/version 后回填创作台。
- **不内嵌他人原图像素**；预览用单独可选 cover URL（本站私有资产，仅同会话可读）；导入后提示上传「自己的」底图。
- 保存时记录 `template_id`、用户选中的候选风格标签与当前结果封面；站内「我的配方」可列出并一键套用。

### 5.2 Qoder SKILL.md 导出

同一配方可一键导出为 Agent Skills 目录格式（SKILL.md + 可选参考文件），安装进 Qoder 等 Agent 工具执行。形成「作品 → 配方 → Agent 技能」沉淀链条。

## 6. 二期需求：图片导入与管理

- 「原图—生成图—提示词—Skills」可归档、可检索、可按画册讲故事；不是网盘。
- **画册呈现**：复用 MIT 开源项目 `HaichaoLihc/create-photo-flipbook-ui` 的 3D 翻页书运行时与模板，把用户作品集生成可翻页的画册页面。
- **链接导入**：一期已内置轻量图文链接解析（扩展项）；深度需求（视频原画、实况照片、主页批量、快手/B站/视频号等）由本地工具「拾影」（Shiying，GPL-3.0，独立运行）承担——拾影下载后导入图派。拾影保持独立进程，不并入图派代码（协议边界见注意事项）。
- 检索可参考 Apache-2.0 的 `gcui-art/album-ai`（相册对话检索）。

## 7. 三期需求：社区

- 公开作品页：作品 + 完整配方（提示词/参数/模型）。
- 一键「用此 Skills 再做一张」：fork 别人的技能套自己的底图。
- 轻量共创：公开任务、评论与二次创作链条（类 DeepSeek Harness 参与式）。
- 一期钩子：作品可携带完整配方离开本站（Skills 导出即接口）。
