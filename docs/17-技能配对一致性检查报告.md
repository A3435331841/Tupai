# 17 · 技能演示「原图 → 作品」配对一致性检查报告

> 检查日期：2026-11-22｜检查人：AI 主执行 Agent（逐张目检）｜事实源：`docs/16-技能演示与语料批次.md` 与 `.scratch-20261119/` 生成记录
> 范围：社区「技能演示」全部 **266 个技能 × 20 对 = 5320 对**（模型 agnes-image-2.5-flash，产物实际均为 .jpg）。
> 口径：**pass** = 主体一致 + 标志效果达成 + 演示语义成立；**partial** = 效果弱 / 核心文字乱码 / 虚构次要元素 / 输入类型不符；**fail** = 主体无关或核心主体无中生有。
> 修复已落地：选图路由按 `input_type` 匹配 + 补充输入 + 0 分门禁，见 `docs/18-技能配对路由修复记录.md`。

## 0. 结论摘要

1. **封面配对达标率仅 39.8%**：pass 106 / partial 58 / fail 102。用户感知的「原图与生成图根本不一致」属实，且是系统性问题而非个别技能。
2. **问题主因是选图路由，不是模型能力**：156 个问题技能改用「语义匹配输入 + 技能原 prompt」以 seedream_5.5 复测，**156/156 全部达标**（其中 14 项经二次换输入/补对白复测）。同一 prompt 换对输入即成立，证明 flat 轮转选图把天文/风景/静物语料配给人像/产品/食物技能是主导根因。
3. **画册内页比封面更糟**：51 个技能封面达标但内页存在 0 分配对（album_risk）。抽查 8 个技能的首个 0 分对，**8/8 主体与构图完全无关**，Agnes 自动评分可信，可直接用作门禁信号。
4. 次要根因：模型中文/英文标题与标签文字能力弱（乱码）、部分技能标志效果未生效、身份保持弱个案、修复类技能被喂干净现代照、特殊输入类型（线稿/老照/分镜/作业纸）语料缺失。
5. 平台侧缺陷：image_edit 批量请求中若任一输入图触发内容预审，**整批静默少返一张**并报 `Length mismatch`，无逐条错误定位（本次以二分法定位到海滩双人照 URL）。

## 1. 检查方法

1. **盘点**：合并 `技能总表.json`、`生成任务.jsonl`、`配对审核.jsonl`、`种子排序.json`、`分类结果.jsonl`，产出 `盘点.json`（每技能 20 对路径、Agnes 评分、封面 orig→work）。
2. **封面目检**：拼 67 张封面拼图（4 技能/张，左原图右作品，含 id/名称/类目/评分），逐张目检写 `判定/b01–b23.json`，合并 `判定汇总.json`。
3. **内页抽查**：对 album_risk 技能取首个 0 分对拼 `内页抽查.jpg`（8 对）目检复核评分可信度。
4. **重生成验证**：对 156 个 partial/fail 技能，用 `image_edit(seedream_5.5)` + 技能原 prompt + `Avoid: ` + negative + **语义匹配输入**复测；缺特殊输入时先合成 14 张 fitted 输入（动漫特写/怪兽涂鸦/菜单草图/六格分镜/作业纸/漫画线稿/建筑线稿/破损老照/黑白老照/褪色老照/撕碎照/双人常服/带标签香水瓶/手写食谱）。按 10 条/批共 16 批执行。
5. **对照固化**：下载 156 张重生成图与对应输入图，拼 39 张「输入原图｜重生成」对照图（`重生成对照/对照-001..039.jpg`）。

## 3. 根因分析

1. **选图路由缺陷（主导）**：批量生成按 flat 轮转取语料，未校验技能语义与语料类目匹配。人像/产品/食物/宠物技能拿到天文、风景、建筑、静物图，模型只能「无中生有」补主体 → fail。证据：156 项换匹配输入后同 prompt 全达标；`street-soda-ad` 误配玻璃茶壶、`recipe-editorial` 误配莓果杯、`perfume-scene-restage` 误配茶壶等个案换输入即 pass。
2. **文字能力弱**：标题/刊头/标签/对白类技能（色卡、单词卡、漫画气泡、杂志刊头）在 agnes-image-2.5-flash 下大面积乱码或空白。seedream_5.5 复测中 vocab-label-cards 14 组英/IPA/中文、product-exploded 13 项中文零件清单、character-sheet 中文三视标签、showa/monochrome-city/travel-mag 中文刊头均清晰 → 属模型差异，可换模型或后处理解决。
3. **标志效果未生效**：部分技能输出仅「换了个滤镜」，缺少技能定义的核心变换（如撕裂、爆炸分解、移轴、选择性着色），判 partial。
4. **身份保持弱个案**：换装/合影类技能人脸或服装漂移（pixar-twin 首测黑T vs 黄夹克），复测强调同装后成立。
5. **修复类输入错配**：old-photo-restore 等被喂干净现代彩照，「修复」语义不成立；合成破损/泛黄/撕碎老照后复测达标。
6. **封面达标≠画册达标**：51 个技能封面 pass 但内页 0 分对成片出现（见 §5），说明路由缺陷在 20 对全量上持续作用，封面只是抽样幸存。
