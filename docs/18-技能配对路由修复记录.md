### 1.4 0 分门禁（新增）

`代码仓库/dev/媒体采集/配对审核-20261120.mjs`：

- `--tasks` 指定任务文件；`--final` / `--gate-out` 隔离输出；`--gate-only` 复用已有评分不调 API。

## 3. 使用方法

```powershell
cd 代码仓库

# 1) 生成匹配版任务（不覆盖历史）
node dev/媒体采集/生成任务构建-20261119.mjs --out=../.scratch-20261119/生成任务-修复.jsonl

# 2) 生成（断点续传；注意先备份/隔离 生成结果，避免覆盖旧图）
node dev/媒体采集/agnes-批量.mjs generate --work=../.scratch-20261119/生成任务-修复.jsonl --conc=8

# 3) 审核 + 门禁
node dev/媒体采集/配对审核-20261120.mjs --tasks=../.scratch-20261119/生成任务-修复.jsonl --final=../.scratch-20261119/种子排序-修复.json --gate-out=../.scratch-20261119/门禁-修复.json --gate-zero
# 注意：--slots 与 --gate-zero 不可组合（slots 每技能只审前 N 对，评分不足 20 会全部判「未审完」并以退出码 1 失败）

# 4) 只重跑指定技能（输出隔离，避免覆盖旧图）
node dev/媒体采集/生成任务构建-20261119.mjs --only="skill-a,skill-b" --out=../.scratch-20261119/修复重跑N任务.jsonl --out-prefix="修复重跑N/" --report=../.scratch-20261119/修复重跑N任务-路由报告.json
node dev/媒体采集/agnes-批量.mjs generate --work=../.scratch-20261119/修复重跑N任务.jsonl --conc=8
# 审核时必须给 id 换唯一后缀（否则会复用旧评分）
node dev/媒体采集/配对审核-20261120.mjs --tasks=../.scratch-20261119/修复重跑N审核任务.jsonl --conc=8 --final=../.scratch-20261119/修复重跑N-排序.json --gate-out=../.scratch-20261119/修复重跑N-门禁.json
```
