## 2. 入口协议

公开作品详情弹窗新增按钮：

> 心语理解（需本机）

点击打开：

```text
http://127.0.0.1:8767/?import=tupai&work_id=wk_...
```

设计取舍：

- 不在 HTTPS 图派页面直接 fetch HTTP 心语，避免 CORS 和混合内容问题；
- 不把 POST 或私有数据交给本地 Agent；
- 心语未启动时，图派页面保持可用，仅新标签页打开失败；
- 不自动发布、fork 或改写作品。
