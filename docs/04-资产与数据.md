## 1.1 运行时副本规则（关键）

`代码仓库/web/public/` 是**运行时派生副本，不是第二份源**：

| 运行时路径 | 源文件 | 派生 |
|---|---|---|
| `/brand/logo-horizontal.svg` | `资产仓库/brand/logo/标志-横版.svg` | 否 |
| `/brand/logo-icon.svg` | `资产仓库/brand/logo/标志-图标.svg` | 否 |
| `/templates/<id>.webp` | `资产仓库/templates/<id>/封面.webp` | 是（压缩版） |
| `/gallery/g06,g07,g09,g10,g12–g15.jpg` | `资产仓库/media/licensed/*.jpg`（中文名，如 咖啡午后.jpg） | 否 |
| `/gallery/g16–g22.png` | `资产仓库/media/generated/*.png`（中文名，如 周末市集.png） | 否 |
| `/home/hero-street.webp` | `资产仓库/media/derived/首页主视觉.webp` | 是（源 `designs/pages/home/v02.../assets/主视觉.png`） |
| `/samples/demo-night.jpg` | `资产仓库/media/derived/夜景演示原图.jpg` | 是（降质废片演示版） |

变更流程：**改源 → 同步 public → 更新 `运行时映射.json` 的 sha256 → build + 404 检查**。禁止直接在 public 改图。

## 1.2 命名与版本

- **资产文件用中文**（可读性优先）：`总索引.md`、`封面.webp`、`提示词.md`、`咖啡午后.jpg`、`品牌规范.md`。
- **技术标识保留英文**：`templates/<id>/` 目录名（API id）、版本目录 `vNN-YYYYMMDD-intent`、`public/` 运行时路径、第三方 Skills、`index.html` 入口。
- 资产仓库内目录用英文 kebab-case（结构稳定）；代码文件遵循框架惯例（组件 PascalCase）。
- 中文化不改变功能：源文件改名须同步 ① HTML 内相对引用 ② `运行时映射.json` 的 `source_path`；`public/` 路径不动。
- 版本目录：`vNN-YYYYMMDD-<intent>`；**禁止** 最终版/新版/old/final/copy。
- 状态枚举：`concept | review | approved | superseded | archived`。
- 当前版本由页面 `索引.md` 指向，不通过改名表达。

## 2. 数据规则

- 任何入库资产必须有来源与协议记录（`manifests/资产清单.json` 的 `origin`/`license`）；协议不明的不进公开站点。
- 用户真实废片（回归测试用）**不入公开仓库**，仅本地测试，测后删除。
- 模板样片优先 AI 生成（无肖像权问题）；不用真人照片做公开模板封面。
- 站内 `web/public/samples/demo-night.jpg` 是 Unsplash 授权原图的「废片演示版」：降亮度、轻模糊、重压缩，用于一键试玩「暗光聚餐 → 夜景提亮」；Unsplash License 允许修改，源图 id 记录在本地 MANIFEST。新增/替换演示图必须同步 LICENSE 与来源记录。
- 治理后盘点：`资产仓库/` 共 117 条资产记录（81 个唯一 sha256；29 组为 v02 原型自包含副本，已在清单用 `duplicate_of` 标记，保留以免破坏原型 HTML）；根目录旧版 113 条清单已归档到 `archive/manifests-legacy-20261118/`。
