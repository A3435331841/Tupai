# 图派 · 资产与数据

> 版本 v3.1 · 2026-11-17 · 资产目录规范、首批数据来源、开源项目集成清单。

## 1. 目录规范

```
资产仓库/
├─ templates/          # 模板资产：每模板一个目录
│  └─ <slug>/          # cover.png(封面示意) + prompt.md(提示词/说明/特征标签tags) + samples/(样片)
├─ test-images/        # 公开测试底图（回归用），每张附来源与协议
│  └─ manifest.csv     # 文件名,来源URL,作者,协议,用途
├─ skills-source/      # 从 GitHub 提炼的提示词/Skills 原料与出处记录
│  └─ sources.md       # 仓库,协议,提炼了哪些条目,边界说明
└─ demo/               # 首页试玩样例图、演示脚本用图
```

规则：
- 任何入库资产必须有来源与协议记录；协议不明的不进公开站点。
- 用户真实废片（回归测试用）**不入公开仓库**，仅本地测试，测后删除。
- 模板样片优先 AI 生成（无肖像权问题）；不用真人照片做公开模板封面。

## 2. 模板样片生产（双通道）

| 通道 | 方式 | 负责 |
|---|---|---|
| GPT 手动 | Qoder 出每模板提示词 → 用户用 GPT 出图 → 回传挑选 | U（M0-8） |
| Agnes 免费 | 直接用 `agnes-image-2.5-flash` 按模板提示词批量出样片（免费，20 RPM 限速） | Q |

两通道互为备份：GPT 样片质量不满意或延迟时，Agnes 通道顶上，不阻塞 M1。
每模板最终需要：1 张封面示意 + ≥3 张回归样片（M3 质量门）+ 特征标签 tags（风格/场景/主体，供相似检索，见开发文档 §4.7）。

- 集成方式：二期画册直接复用 MIT 运行时与模板，保留版权声明；图派负责把 Asset 库的照片集喂给它生成画册页。

### 4.2 链接解析：拾影 Shiying（本地配合工具）

- 位置：独立本地项目（GPL-3.0-or-later，FastAPI 本地服务 127.0.0.1:8766，不并入本仓库）
- 能力：小红书/抖音/抖音精选/快手/B站/YouTube/微信视频号 链接解析，原画下载、图集、实况照片配对、按作者归档。
- **协议边界：GPL 代码不得复制进图派**。集成方式：
  - 一期：文档引导用户「拾影下载 → 截帧/选图 → 上传图派反推」，两工具各自独立。
  - 二期候选：浏览器前端调用拾影 localhost HTTP API（独立进程通信，不产生 GPL 衍生），需用户本机运行拾影；公开参赛站不依赖此路径。
