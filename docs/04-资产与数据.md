## 1.1 运行时副本规则（关键）

`代码仓库/web/public/` 是**运行时派生副本，不是第二份源**：

| 运行时路径 | 源文件（迁移后） | 派生 |
|---|---|---|
| `/brand/logo-horizontal.svg` | `资产仓库/10-品牌资产/标志/在用/标志-横版.svg` | 否 |
| `/brand/logo-icon.svg` | `资产仓库/10-品牌资产/标志/在用/标志-图标.svg` | 否 |
| `/templates/<id>.webp` | `资产仓库/60-模板资产/<id>/封面.webp` | 是（压缩版） |
| `/gallery/g06,g07,g09,g10,g12–g15.jpg` | `资产仓库/40-图片资产/真实授权/*.jpg`（如 咖啡午后.jpg） | 否 |
| `/gallery/g16–g22.png` | `资产仓库/40-图片资产/AI生成/在用/*.png`（如 周末市集.png） | 否 |
| `/home/hero-street.webp` | `资产仓库/40-图片资产/派生加工/首页主视觉.webp` | 是（源为首页 v02 主视觉） |
| `/samples/demo-night.jpg` | `资产仓库/40-图片资产/派生加工/夜景演示原图.jpg` | 是（降质废片演示版） |

变更流程：**改源 → 同步 public → 更新 `90-元数据/运行时映射.json` 的 sha256 → build + 404 检查**。禁止直接在 public 改图。

## 1.2 命名与版本（全面中文化，详见 docs/13）

- **目录与文件均用中文**（可读性优先）：`10-品牌资产/`、`40-图片资产/AI生成/`、`在用/`、`首页主视觉-v02-显影暗房.webp`。
- **技术标识保留英文**：`<模板id>/`（API id）、版本目录 `vNN-YYYYMMDD-<中文意图>`、`public/` 运行时路径、第三方 Skills 原始文件、`index.html` 入口、资产 `id`（英文 slug）。
- 多维分类（用途/风格/场景/页面/主题/合规）用受控标签，不建目录；词表见 `90-元数据/标签词表.json`。
- 中文化不改变功能：源文件改名须同步 ① HTML 内相对引用 ② `90-元数据/运行时映射.json` 的 `source_path`；`public/` 路径不动。
- 版本目录：`vNN-YYYYMMDD-<中文意图>`，`v00-` 专用于未采纳方案；**禁止** 最终版/新版/old/final/copy。
- 状态六态：`draft | review | approved | superseded | discarded | archived`（"在用"沿用 `approved`）；状态在目录分区、清单字段、版本说明三处同步。
- 当前版本由页面 `索引.md` 指向 + `status=approved`（单元内唯一），不通过改名表达。

## 2. 数据规则

- 任何入库资产必须有来源与协议记录（`90-元数据/资产总清单.json` 的 `来源`/`协议`）；协议不明的不进公开站点。
- 用户真实废片（回归测试用）**不入公开仓库**，仅本地测试，测后删除。
- 模板样片优先 AI 生成（无肖像权问题）；不用真人照片做公开模板封面。
- 站内 `web/public/samples/demo-night.jpg` 是 Unsplash 授权原图的「废片演示版」：降亮度、轻模糊、重压缩，用于一键试玩「暗光聚餐 → 夜景提亮」；Unsplash License 允许修改，源图 id 记录在本地 MANIFEST。新增/替换演示图必须同步 LICENSE 与来源记录。
- 资产总清单（`90-元数据/资产总清单.json`）150 条（approved 88 / archived 44 / discarded 14 / superseded 4），路径 150/150 有效；字节相同的原型副本以 `重复自` 标记、决策=留档；历史清单归档在 `99-归档/旧清单/`。精确统计见 `docs/13 §12`。
- 六态：`draft/review/approved/superseded/discarded/archived`；"在用"沿用 `approved`；六维标签词表见 `90-元数据/标签词表.json`，字段定义见 `字段规范.json`。
- 清单 sha256 以 Git 暂存对象的字节为准；Windows 自动转换换行符时，工作区内 SVG 的实际文件哈希可能不同，不代表提交对象损坏。
