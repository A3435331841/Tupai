## 3. 参赛叙事

- **初心**：让拍照不好看的人，也能有别样的作品去发布——可以不发原图。
- **差异点**：
  1. 零门槛：上传一张图或说一句话，自动优化 prompt + 相似模板预览，不会写提示词也能出片
  2. 真实 AI 出图（Agnes 免费模型，游客免登录实时生成）
  3. 原图可藏：隐私设计是产品初心的一部分
  4. Skills 双格式：配方 JSON + Qoder SKILL.md，「作品→配方→Agent 技能」呼应 Qoder 生态
  5. 扩展：抖音图文链接站内提取灵感（合规表述为「灵感参考」，不宣传抓取）
- **Qoder 全链路**：需求梳理→代码→资产→部署→发帖全程在 Qoder 完成，过程截图留档供帖子引用。

## 4. 60 秒演示脚本（MVP 主路径：图片或文字）

1. （0–10s）打开首页 → 点「一键试玩」，样例废片入场
2. （10–25s）系统自动优化出提示词候选 + 弹出相似模板预览 → 一键套用 → 生成 → 真实出图，原图/结果并排
3. （25–40s）换文字入口：输入「想要胶片感的旅行照」→ 自动扩写提示词 → 直接生成第二张
4. （40–55s）导出 Skills（JSON + SKILL.md）→ 展示「下次一键复用」
5. （55–60s）点下载，强调「原图全程私密，作品带 AI 标识」

加分项（若链接解析稳定）：演示粘贴抖音图文链接 → 站内提取图文 → 反推出提示词。不稳定则不纳入演示。
稳定性保障：生成链路内置排队与降级机制（降级时界面明确标注），Agnes 限流时演示不中断。
