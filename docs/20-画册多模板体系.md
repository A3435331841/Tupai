# 画册多模板体系（v1.4，2026-11-23）

> 用户对单一「一张图 + 上下页」画册呈现不满意，明确要求做**多模板体系**，并指出可学习借鉴已开源的相关代码。
> 本文是多模板画册的事实源；已纳入 git 跟踪并提交（最近更新 0a2df5d，2026-11-23）。

## 1. 参考与协议边界

**参考项目**：[HaichaoLihc/create-photo-flipbook-ui](https://github.com/HaichaoLihc/create-photo-flipbook-ui) · MIT · 691★/68 forks（2026-11-23 复核）。

该项目的 `ui-collections/` 提供 9 套可选模板：Library 书架、2D Book、2D Book Editor、3D Book 1/2、Card Gallery、Image Atlas、Photo Ring、Stream/Undertow、Negative Sleeves 胶片档案。作者另有 `visual-experience-demo`（照片 Explore/Flow）、photo→3D 纪念品商店 skill、`anchor-website`、`WikiGen` 等相关项目。

**协议红线**：README 明示 `ui-collections/3d-book-1/` 中的改编代码及所有照片/媒体**不在 MIT 授权内**。因此本项目：
- ✅ 借鉴**概念与设计语言**（精装书 / 杂志跨页 / 环形卡片 / 胶片条）；
- ✅ 用零依赖纯 HTML/CSS/JS **自行实现**；
- ❌ 不搬运其运行时、模板代码或媒体资源。

## 2. 已实现九套模板

实现落在 `代码仓库/server/album-styles.mjs`，`routes.mjs` 的 `albumPageHtml()` 只做调用包装（保持原函数签名与位置，便于回滚）。

| 模板 id | 名称 | 视觉 | 交互 | 适用 |
|---|---|---|---|---|
| `hardcover` | 3D 精装（默认） | 暗场 + 曲页阴影 + 书脊高光 | 3D 翻页 0.7s 缓动、方向键、保存这张 | 沉浸、仪式感 |
| `editorial` | 杂志跨页 | 暖米底 + 左右双页 + 刊头/页码 | 按"跨页"翻（20 图=10 页） | 安静阅读、作品集 |
| `cards` | 卡片画廊 | 浅灰底 + 白框编号卡 + 弧形排布 | 环形旋转、点卡选中、橙光晕 | 轻快浏览、社媒 |
| `film` | 胶片档案 | 暗底 + 齿孔胶片条 + 帧号 | 横向滚动吸附、逐帧聚焦 | 摄影感、胶片调性 |
| `atlas` | 影像图谱 | 深蓝空间 + 同心圆分组 + 金框 | 主题/组号检索、点图聚焦、方向键/Esc | 空间档案、探索感 |
| `stream` | 光影瀑布 | 暗底 + 三列错落瀑布 + 视差淡入 | 滚动 IntersectionObserver 淡入、上下页跳转定位 | 沉浸浏览、图海 |
| `webgl` | 真曲页 | 暗场 + 原生 WebGL 曲面书页 | 顶点着色器真实卷曲翻页；无 WebGL 自动降级提示 | 真实翻书质感、技术展示 |
| `negatives` | 底片夹 | 暗底齿孔胶片 + 页角小预览 | 拖动胶片条、点帧放大、正片↔负片反转（N键）、Esc 返回 | 摄影底片感、逐帧检视 |
| `editor` | 可编辑书 | 暖米活页 + 左编辑面板 | 页面/图片/文字块编辑、背景与文字色、层级调整、localStorage 保存、**纯 JS 导出整本 PDF** | 二次创作、下载留念 |

> 三套新增（2026-11-23 按用户「一个个接入」）：`atlas` 按序号每 4 张一圈分组（画册无真实年份元数据，用作品号代替开源项目的年代）；`stream` 用纯 CSS 多列 + IntersectionObserver 视差淡入（非 three.js）；`webgl` 用原生 WebGL（零依赖，不引 three.js）顶点着色器做柱状卷曲，支持 `getContext('webgl')` 检测降级。
> **WebGL 纹理方向坑**：需同时 `UNPACK_FLIP_Y_WEBGL=true` 且 UV.y=`1-j/Y`，否则人像上下颠倒；顶点用 vec3 否则 `p.z` 编译报错。

**统一能力**（九套全有）：
- 模板切换器：页面底部 9 个胶囊按钮（由 `ALBUM_STYLES.map` 逐项生成），点击即切（`?style=` URL 同步，刷新保持）；非法/缺省值回退 `hardcover`。
- 每张展示图带 AI 角标；`hardcover` 的「保存这张」在 canvas 上合成「AI 生成 · 图派」再下载。
- 图片一律相对路径 `img/{id}?watermark=1`（深层分享路径写死 `/api/v1` 会被平台拦截，见 docs/14 F-10）。
- 复用既有 `liveAlbumIds()` 软删校验、分享 token/过期校验、`no-store` 响应头；模板切换不触碰资产。

## 3. 路由与兼容

- 分享页 `GET /api/v1/share/{token}/page?style=<id>`：`style` 白名单校验后传入模板渲染。
- 旧行为兼容：不带 `?style=` 时默认为 `hardcover`，视觉与原页面同类但更精致。
- 只读语义不变：模板切换是前端 URL 参数，不写库、不改变分享权限。
