# 图派 · 注意事项

> 版本 v3.0 · 2026-11-17 · 安全、隐私、协议、工程与赛务红线。开发前通读，评审前复查。

## 1. 安全红线（最高优先级）

1. **API Key 绝不外泄**：`docs/references/agnes-api.md` 内含 10 个真实 Key。
   - 该文件与任何含 Key 的文件：**不进 git 提交、不进前端代码、不进公开站点、不发聊天群**。
   - 建仓时 `.gitignore` 必须包含 `docs/references/agnes-api.md`、`*.key`、`agnes key.txt`、`.env*`。
   - 运行时 Key 只存 Sites Secret，仅云函数读取；日志只记 key 别名。
   - 若怀疑泄露：立即去 Agnes 控制台作废重发。
2. **模型白名单硬校验**：只允许免费模型 ID（见 03 文档），防止误调付费模型扣费。
   - 一期不引入任何按次/按量付费的外部服务。DeepSeek 搜索工具（¥5/1000 次成功请求、无图片搜索）**不进 MVP**，调研结论见 08 §5。
3. 上传校验：格式/大小上限、速率限制、每游客生成配额，防公开站被刷。
4. 日志不落原图像素与 Key 明文。

## 2. 隐私红线（产品初心）

1. 原图（original）默认 private，任何发布动作只触及 result + Skill 元数据。
2. **视觉分析隐私（M0 已定案）**：2026-11-17 实测 Agnes 视觉接受 data URL → 用户原图 base64 直传分析，全程不落公网，无需临时公开机制。图生图同样 base64 直传。链接解析图用其公开 CDN URL。临时公开对象方案仅作历史备选，一期不实现。
3. Agnes 返回的结果 COS URL 是公开链接 → 必须转存本站后再展示，避免作品长期挂在第三方公开存储。
4. Skills 不内嵌他人原图像素。
5. 所有 AI 结果图与下载物带「AI 生成」标识（Sites 亦强制平台标识）。

## 4. Agnes 工程坑（速查）

- Key 与站点配对（CN key 打 CN 站），401 先查站点再查 key。
- 20 RPM/key：限速按 15 控 + 轮换 + 429 退避；全池冷却降级 Mock。
- `response_format` 只在 `extra_body`；图生图在 `extra_body.image`。
- `agnes-2.5-flash` 隐式推理：max_tokens ≥ 512。
- 出图同步 8–20s：云函数超时必须 M0 实测，不够就拆「提交+轮询」两段。
- 免费体验价可能结束：发布前与决赛前各复查一次账单/价格页。

## 5. 赛务红线

1. 截止 **2026-11-30 18:00**（报名+发布+发帖），M4 留半天缓冲，绝不卡点。
2. 站点必须 **public 访问、评委免登录走通主路径**；发布后用无痕窗口+手机复验。
3. 天池帖必需要素齐全（见 06 文档），所用 Qoder 账号与报名一致。
4. 演示依赖真实出图，但必须有 Mock/预置样片兜底——评委演示时 Agnes 限流不能白屏。
5. 不做完整社区、不强制登录、不依赖无备用的外部服务。

## 6. 内容合规

- 参考图可能来自他人作品：仅作个人学习/灵感反推，**不公开 redistribute 参考图本身**；Skills 只带提示词不带参考图像素。
- 模板与样片不用真人肖像做公开封面；AI 人像结果提示用户注意肖像与平台规则。
- /legal 页声明：第三方模型（Agnes）、AI 生成内容、隐私处理。

## 7. 链接解析合规（F12 扩展模块专项）

**法律风险评估（结论：可做，但必须收敛为"尽力而为的可选扩展"）**：

| 层面 | 评估 | 对策 |
|---|---|---|
| 著作权 | 只经视觉/文本分析提炼 prompt，不存储传播原图与文案；prompt 属思路/风格层面信息，不构成对原作表达的复制，风险低 | 解析内容用后即焚：不落 Asset 库、不进日志、不公开展示；产出只留提炼后的 prompt |
| 平台规则 | 抖音用户协议禁止未授权抓取；规模化/商业化解析有不正当竞争与违约风险 | 只做单条图文链接、用户主动粘贴触发；**不做批量/主页/定时爬取**；控制频率；失败即降级 |
| 个人信息 | 文案/图片可能含他人个人信息 | 不存储作者信息、账号、评论等任何个人数据 |
| 技术连带 | 拾影 GPL 代码与浏览器签名方案不可搬用 | 自研轻量 HTTP 解析；云 IP 可能被风控，spike 验证，不通则模块延后 |

**执行红线**：
1. MVP 不依赖链接解析；解析失败必须有顺滑的手动上传降级。
2. 参赛叙事不宣传「破解/抓取抖音」，表述为「灵感参考：粘贴链接提取风格灵感」。
3. 解析临时缓存生命周期 ≤ 单个 Job；Job 结束清理，含失败路径。
4. 上线前复查：站点无任何抖音原图/文案的持久化存储与公开展示。
